# Графические элементы архитектурных стилей для генератора зданий

Источник списка стилей: таблица значений `building:architecture` (OSM, русская вики), 29 стилей (30 значений тега) в трёх периодах.
Для каждого стиля ниже перечислены элементы, из которых генератор может собрать узнаваемое здание.

Состояние кода на момент составления: тег `building:architecture` в `src/` нигде не читается; год постройки
(`start_date`) используется только для панорамных окон и витрин.

## 1. Словарь элементов

Все стили описаны одним набором параметрических примитивов. В скобках отмечено, что из этого генератор уже
рисует (`building-mesher.ts`, `roof-shapes.ts`, оконный шейдер), остальное нужно добавлять.

**Силуэт и кровля**

| Код | Элемент | Есть сейчас |
|---|---|---|
| `roof.*` | форма кровли: flat, gabled, hipped, half-hipped, mansard, gambrel, skillion, dome, onion, pyramidal, cone, sawtooth | да (`roof:shape`) |
| `parapet` | парапет над карнизом | да |
| `attic` | аттик: глухая стенка над карнизом, прямая, ступенчатая или криволинейная | нет |
| `pediment` | фронтон: треугольный, лучковый, разорванный | нет |
| `gable` | декоративный щипец на фасаде: треугольный, ступенчатый, фигурный | нет |
| `tower` | башенка: угловая или осевая, с завершением (шатёр, купол, луковица, шпиль) | частично (части здания из OSM) |
| `setback` | уступы объёма кверху | только из частей OSM |
| `risalit` | ризалит: выступ части фасада на 0,3–1,5 м | нет |
| `bay` | эркер: гранёный, прямоугольный или полукруглый, на 1–N этажей | нет |
| `chimney` | дымовые трубы | да |

**Членение стены**

| Код | Элемент | Есть сейчас |
|---|---|---|
| `plinth` | цоколь другим цветом или материалом | да |
| `rust` | руст: горизонтальные швы на 1–2 нижних этажах или по всей стене | нет |
| `belt` | межэтажная тяга (пояс) | нет |
| `cornice` | венчающий карниз с выносом; варианты: гладкий, с зубчиками, с кронштейнами | нет |
| `pilaster` | пилястры или лопатки между осями окон, на 1 этаж или на несколько (большой ордер) | нет |
| `portico` | портик: N колонн + фронтон или аттик, с выносом от стены | нет |
| `arcade` | аркада или ряд арочных ниш первого этажа | нет |
| `quoin` | выделенные углы (угловой руст) | нет |
| `stripe` | полосатая стена: чередование двух цветов рядами | нет |
| `fin` | вертикальные рёбра или пилоны на всю высоту | нет |
| `band` | сплошные горизонтальные ленты: окна и простенки чередуются полосами | нет |
| `curtain` | навесная стеклянная стена с сеткой импостов | частично (панорамные окна) |
| `balcony` | балконы: открытые, остеклённые | да |
| `storefront` | витрины первого этажа | да |

**Окна** (сейчас: сетка 4 × 3 м в шейдере, флаги panoramic, shops, residential, blind)

| Код | Параметр | Значения |
|---|---|---|
| `win.ratio` | пропорция проёма, высота : ширина | 2:1 … 1:3 |
| `win.step` | шаг осей | 2–6 м |
| `win.head` | перемычка | прямая, лучковая, полуциркульная, стрельчатая, подковообразная, килевидная, трапециевидная |
| `win.frame` | обрамление | нет, наличник, сандрик прямой или треугольный, эдикула, замковый камень |
| `win.glazing` | расстекловка | цельное, крест, сетка 6/6, мелкая в верхней трети, горизонтальные полосы |
| `win.group` | группировка | одиночные, спаренные, тройные, ленточные, угловые |
| `win.special` | особые проёмы | круглое, овальное, окно-роза, термальное (полукруг из трёх частей), шестиугольное |
| `win.shrink` | убывание высоты окон кверху | да / нет |

**Декор-вставки** (плоские панели или простая геометрия, размещаемые по правилам)

`keystone` замковый камень · `relief` барельефная панель · `frieze` орнаментальный фриз ·
`kokoshnik` ряд кокошников · `merlon` зубцы парапета · `pinnacle` пинакли · `buttress` контрфорсы ·
`balustrade` балюстрада · `spire` шпиль · `vase` вазы и обелиски на парапете · `lombard` аркатурный пояс под карнизом

## 2. Стили 1800–1900

### `neoclassicism` — классицизм (в России 1760–1830-е; неоклассицизм 1900–1910-х)
- **Силуэт:** строгая симметрия, центральный `risalit` с `portico` (4–8 колонн) и треугольным `pediment`; `roof.hipped` с малым уклоном; изредка купол-ротонда по центру.
- **Стена:** `rust` на первом этаже, гладкий верх, `belt` над первым этажом, `cornice` с зубчиками.
- **Окна:** `win.ratio` 2:1, прямые; сандрики только на втором (парадном) этаже; `win.shrink`, верхний этаж с почти квадратными окнами.
- **Декор:** `keystone` над окнами первого этажа, гладкий фриз.
- **Палитра:** жёлтая охра, бледно-розовый, светло-серый, бледно-зелёный; все детали белые; кровля зелёная или серая.
- **Ключ:** портик с фронтоном + жёлто-белая схема.

### `empire` — ампир (1-я треть XIX века)
- **Силуэт:** как классицизм, но крупнее и проще; над портиком чаще ступенчатый `attic`, чем фронтон; низкий купол.
- **Стена:** большие гладкие плоскости без дробления; `portico` из массивных колонн без баз (дорика, тоскана); `arcade` из арочных ниш на первом этаже.
- **Окна:** прямые без наличников на гладкой стене; `win.special` термальное в центре или в нишах; арки с крупным `keystone`.
- **Декор:** `relief` (венки, воинская арматура, маски) редкими вставками на гладком поле.
- **Палитра:** жёлтый с белым, светло-серый.
- **Ключ:** гладкая стена + аттик + полукруглое трёхчастное окно.

### `moorish_revival` — неомавританский стиль
- **Силуэт:** `tower`-минареты по углам, малые купола `roof.onion` или `roof.dome`, `merlon` по парапету.
- **Стена:** `stripe` (два цвета рядами), `arcade` на колонках.
- **Окна:** `win.head` подковообразная или многолопастная, `win.group` спаренные и тройные.
- **Декор:** `frieze` с геометрическим узором, изразцовые вставки.
- **Палитра:** терракота, охра, белый, акценты бирюзой и синим.
- **Ключ:** подковообразные арки + полосатая кладка.

### `pseudo-russian` — псевдорусский стиль (1830-е – 1917, включая русско-византийский)
- **Силуэт:** шатры `roof.pyramidal` и главки `roof.onion` на `tower`; высокие крутые кровли; ярусы `kokoshnik`; крыльцо с шатром.
- **Стена:** красный кирпич с белыми деталями; `belt` в виде узорных кирпичных поясов; `pilaster` на углах.
- **Окна:** `win.head` полуциркульная или килевидная, `win.group` спаренные с «гирькой»; `win.frame` наличник с кокошником.
- **Декор:** `kokoshnik`, `frieze` (поребрик, бегунец), квадратные ниши-ширинки, пузатые столбы крыльца.
- **Палитра:** красный кирпич + белый; кровля зелёная, шатры с шахматным или полосатым узором, главки золотые или синие.
- **Ключ:** шатёр + кокошники + красно-белая стена.

### `eclectic` — эклектика
- **Силуэт:** `risalit` по краям или по центру, угловая `tower` с куполом или шатром, `bay`, `roof.mansard`, фигурные `attic`.
- **Стена:** плотное членение: `rust` внизу, `belt` на каждом этаже, `cornice` с кронштейнами, `pilaster`.
- **Окна:** `win.frame` свой на каждом этаже (сандрик, эдикула, арочное), `win.ratio` 2:1.
- **Декор:** `keystone`, `relief`, `balustrade`, кованые `balcony`.
- **Палитра:** пастельная штукатурка (охра, серо-зелёный, розовый, бежевый) или лицевой кирпич.
- **Ключ:** для генератора это смесь: взять 2–3 набора из соседних неостилей и менять обрамление окон по этажам.

### `georgian` — георгианская архитектура (XVIII век, англоязычные страны)
- **Силуэт:** симметричная кирпичная коробка в 5 осей; `roof.hipped` или кровля за `parapet`; `chimney` по торцам; часто рядовая застройка.
- **Стена:** гладкий кирпич, белые `quoin`, `cornice` с зубчиками, `belt`.
- **Окна:** `win.ratio` 2:1, `win.glazing` сетка 6/6, `win.shrink`; плоская белая перемычка.
- **Декор:** дверь по центру с белым порталом и полукруглым окном-веером над ней.
- **Палитра:** красный или жёлто-бурый кирпич, белые детали, шиферная кровля.
- **Ключ:** кирпич + белые окна сеткой + портал двери.

### `victorian` — викторианская архитектура (1837–1901)
- **Силуэт:** асимметрия; `bay` на 1–2 этажа; крутые `roof.gabled` с фасадными `gable`; высокие `chimney`; `tower` в углу; крыльцо-веранда.
- **Стена:** полихромный кирпич (`stripe`, узорные вставки), терракота.
- **Окна:** `win.ratio` 2:1, `win.glazing` крест или 2/2, `win.head` лучковая или стрельчатая; тройные окна в эркерах.
- **Декор:** резные причелины щипцов, `frieze` из терракоты, гребень по коньку.
- **Палитра:** красный, жёлтый, тёмно-серый кирпич; кровля тёмный шифер.
- **Ключ:** эркеры + крутые щипцы + полосатый кирпич.

### `historicism` — историзм
- Зонтичное значение: конкретный неостиль неизвестен.
- **Генератору:** общий набор историзма: симметрия, `rust` внизу, `belt`, `cornice` с кронштейнами, `attic` или `roof.mansard`, обрамлённые окна. По умолчанию рисовать как `neo-renaissance`, с долей случайных деталей из `neo-baroque` и `neo-gothic`.

### `neo-romanesque` — неороманский стиль
- **Силуэт:** массивный объём, `tower` с `roof.pyramidal`, щипцовый фасад.
- **Стена:** толстые стены, лопатки (`pilaster` без капителей), `lombard` под карнизом и вдоль щипцов.
- **Окна:** `win.head` полуциркульная; `win.group` спаренные и тройные с колонкой; `win.special` окно-роза; малая площадь остекления.
- **Декор:** портал с уступами арок, `stripe` в арках.
- **Палитра:** красный или жёлтый кирпич, серый и песочный камень.
- **Ключ:** полукруглые арки + аркатурный пояс.

### `neo-gothic` — неоготика
- **Силуэт:** вертикаль: `spire`, `pinnacle`, высокие острые `gable`, крутая кровля; `merlon` на гражданских зданиях.
- **Стена:** `buttress` с шагом окон, вертикальные тяги.
- **Окна:** `win.head` стрельчатая, `win.ratio` 3:1, переплёт с каменным узором; `win.special` окно-роза; `bay` на консолях.
- **Декор:** треугольные навершия над порталами, крестоцветы.
- **Палитра:** красный кирпич или серый камень, тёмная кровля.
- **Ключ:** стрельчатые окна + контрфорсы + шпили.

### `pseudo-gothic` / `russian_gothic` — русская псевдоготика (с 1776)
- **Силуэт:** план и симметрия классицизма; круглые и гранёные `tower` по углам с шатрами; `merlon` (в том числе «ласточкин хвост»); `pinnacle` в виде пирамидок.
- **Стена:** красный кирпич, белокаменные детали поверх него.
- **Окна:** `win.head` стрельчатая и полуциркульная вперемешку; белые наличники.
- **Декор:** белый «кружевной» узор (ромбы, кресты, стрелки), `belt` из белого камня.
- **Палитра:** красный + белый.
- **Ключ:** красно-белая стена + зубцы + стрельчатые проёмы на симметричном объёме.

### `neo-byzantine` — неовизантийский стиль (с 1840-х)
- **Силуэт:** широкий пологий `roof.dome` на низком барабане с кольцом окон, вокруг него полукупола; крестово-купольный объём.
- **Стена:** `stripe` (кирпич и камень рядами), `lombard`, `arcade`.
- **Окна:** `win.head` полуциркульная, `win.group` тройные; ряд арочных окон в барабане.
- **Декор:** `frieze`, мозаичные вставки.
- **Палитра:** охра и красный кирпич полосами; купол серый, зелёный или золотой.
- **Ключ:** пологий купол на барабане с окнами + полосатая кладка.

### `neo-renaissance` — неоренессанс
- **Силуэт:** палаццо: прямоугольный блок, плоская или низкая кровля за `balustrade`, очень сильный `cornice`.
- **Стена:** три яруса; `rust` грубый внизу и мельче кверху; `belt` между ярусами; `pilaster` поэтажно; `quoin`.
- **Окна:** первый этаж `win.head` полуциркульная; выше `win.frame` эдикула с чередованием треугольного и лучкового фронтончика.
- **Декор:** `arcade` (лоджия), `keystone`.
- **Палитра:** песочный, охра, терракота, серый камень.
- **Ключ:** трёхъярусная стена + чередующиеся фронтончики окон + тяжёлый карниз.

### `neo-baroque` — необарокко
- **Силуэт:** `roof.mansard` с куполами над `risalit`; разорванные и лучковые `pediment`; фигурные `attic`.
- **Стена:** `pilaster` и колонны большого ордера, раскрепованный `cornice`, сильная пластика (глубокие выступы).
- **Окна:** `win.head` лучковая; пышный `win.frame`; `win.special` овальные окна в мансарде и над порталами.
- **Декор:** `relief` (картуши, волюты), `balustrade`, `vase`, балконы с выгнутой решёткой.
- **Палитра:** голубой, бирюзовый, жёлтый, розовый с белым; либо серый камень.
- **Ключ:** мансарда с куполом + разорванный фронтон + овальные окна.

## 3. Стили 1900–1950

### `art_nouveau` — модерн (1890–1910-е)
- **Силуэт:** асимметрия; криволинейный `attic`; `bay` разной формы; угловая `tower` с вытянутым куполом.
- **Стена:** гладкая штукатурка в сочетании с глазурованным кирпичом; без ордера; текучие линии вместо карнизов.
- **Окна:** на одном фасаде несколько форм: `win.head` подковообразная, криволинейная, большая арка; `win.glazing` мелкая в верхней трети; `win.group` тройные.
- **Декор:** `frieze` из майолики под карнизом, `relief` с растительным мотивом и масками, кованые `balcony`, козырьки на кронштейнах.
- **Палитра:** бежевый, оливковый, серо-голубой, охра, коричневый; цветные фризы.
- **Ключ:** разные формы окон + майоликовый фриз + криволинейный аттик.

### `nothern_modern` — северный модерн (написание тега как в OSM)
- **Силуэт:** высокие острые `gable`, `tower`, `bay`, крутая кровля; асимметрия.
- **Стена:** `plinth` и первый этаж из грубого гранита; выше фактурная штукатурка; декор минимален.
- **Окна:** разные размеры на одном фасаде; `win.head` трапециевидная; `win.special` шестиугольное; `win.glazing` мелкая; малые окна группами.
- **Декор:** редкие `relief` (совы, медведи, шишки), массивный портал.
- **Палитра:** серый гранит, серая, коричневая и тёмно-охристая штукатурка, красная черепица.
- **Ключ:** гранитный низ + острые щипцы + окна со скошенным верхом.

### `functionalism` — функционализм
- **Силуэт:** `roof.flat`, простые сцепленные объёмы, первый этаж на столбах.
- **Стена:** гладкая, без карниза и цоколя.
- **Окна:** `band` или `win.group` ленточные; `win.ratio` 1:2 и шире; угловые окна; вертикальная стеклянная полоса лестничной клетки.
- **Декор:** нет; консольные `balcony` с глухим или трубчатым ограждением, тонкие козырьки.
- **Палитра:** белый, светло-серый.
- **Ключ:** белая коробка + ленточные окна.

### `cubism` — кубизм (в архитектуре прежде всего чешский)
- **Силуэт:** гранёные объёмы, `roof.mansard` с изломом, гранёные `bay`.
- **Стена:** плоскость разбита на наклонные грани (пирамидки, ромбы); гранёные `pilaster`; зигзагообразный `cornice`.
- **Окна:** скошенные откосы; `win.special` шестиугольное; гранёные обрамления.
- **Декор:** призматические `relief` вместо лепнины.
- **Палитра:** серый, охра, белый.
- **Ключ:** кристаллические грани стены и откосов.

### `new_objectivity` — новая вещественность (Германия, 2-я половина 1920-х)
- **Силуэт:** длинные строчные корпуса в 3–5 этажей, `roof.flat`, скруглённые торцы.
- **Стена:** гладкая цветная штукатурка, клинкерный `plinth` и обрамления входов.
- **Окна:** равномерная сетка; `win.ratio` 1:1,5; `win.glazing` горизонтальные полосы; вертикальное остекление лестниц с ровным шагом по длине дома.
- **Декор:** нет; ритм лоджий и `balcony`.
- **Палитра:** белый, плюс насыщенные плоскости: красный, синий, жёлтый, зелёный.
- **Ключ:** длинный плоский дом + цветные плоскости + ритм лестничных клеток.

### `art_deco` — ар-деко
- **Силуэт:** `setback` (зиккурат), корона или `spire` на оси; скруглённые углы у поздних зданий.
- **Стена:** `fin` без капителей на всю высоту; тёмный `plinth`; облицовка камнем.
- **Окна:** собраны в вертикальные полосы между `fin`; простенки под окнами утоплены и декорированы.
- **Декор:** `relief` с геометрией (шеврон, зигзаг, лучи, веер), `frieze` на уступах, металлические акценты.
- **Палитра:** бежевый и серый камень, чёрный гранит, латунь, терракота.
- **Ключ:** уступы + вертикальные пилоны + геометрические панели.

### `modern` — архитектурный модернизм (1900-е – 1980-е)
- Зонтичное значение (функционализм, конструктивизм, баухауз, интернациональный стиль, брутализм).
- **Генератору:** `roof.flat`, без декора, `band` или сетка окон, простые объёмы. Подстиль выбирать по `start_date` и стране: 1920–30-е СССР → `constructivism`, 1920–30-е Европа → `functionalism`, 1950–70-е → `international_style` или `brutalist`.

### `amsterdam_school` — амстердамская школа
- **Силуэт:** волнообразные стены, скруглённые углы, `tower`; крутая черепичная кровля, спускающаяся на стену.
- **Стена:** кирпич с декоративной кладкой (вертикальные ряды, выпуски); криволинейные выступы.
- **Окна:** `win.glazing` горизонтальные полосы («лесенка»); белые рамы; параболические проёмы; `bay`.
- **Декор:** кирпичная скульптура, кованые детали, участки стены, покрытые черепицей.
- **Палитра:** тёмно-красный, коричневый, жёлтый кирпич; оранжевая черепица; белые рамы.
- **Ключ:** кирпичные скруглённые формы + окна с горизонтальной расстекловкой.

### `international_style` — интернациональный стиль (1930–1960-е)
- **Силуэт:** призма-пластина или башня на низком подиуме; `roof.flat`; первый этаж на столбах.
- **Стена:** `curtain` с регулярной сеткой импостов или `band`; каркас читается на фасаде.
- **Окна:** сплошное остекление; модуль 1,2–1,5 м.
- **Декор:** нет.
- **Палитра:** стекло зелёное, серое, бронзовое; сталь; белый бетон.
- **Ключ:** стеклянная призма с ровной сеткой.

### `constructivism` — конструктивизм (СССР, 1920-е – 1-я половина 1930-х)
- **Силуэт:** композиция из сдвинутых и пересекающихся простых объёмов; полуцилиндр лестничной клетки; `roof.flat`; переходы-галереи.
- **Стена:** гладкая, без карниза; столбы под частью объёма.
- **Окна:** `band`; вертикальное остекление лестниц; `win.special` круглое; угловые окна.
- **Декор:** нет; угловые `balcony`, крупные надписи.
- **Палитра:** серая штукатурка, белый, красный кирпич, тёмные рамы.
- **Ключ:** полуцилиндр + ленточные окна + асимметрия объёмов.

### `postconstructivism` — постконструктивизм (1932–1936, до 1941)
- **Силуэт:** конструктивистский объём, ставший симметричным; ступенчатый `attic`.
- **Стена:** `pilaster` и колонны квадратного сечения без капителей; упрощённый `cornice`; плоские прямоугольные рамки вокруг групп окон; кессоны.
- **Окна:** квадратные; `win.special` круглое в верхнем этаже; лоджии с квадратными проёмами.
- **Декор:** редкие `relief`, `vase`.
- **Палитра:** серый, охра, тёплый бежевый.
- **Ключ:** квадратные пилоны без капителей + рамки + квадратные окна.

### `stalinist_neoclassicism` — сталинский ампир (середина 1930-х – 1955)
- **Силуэт:** симметрия; у высотных зданий ярусная `setback`-композиция с `tower` и `spire`; у жилых домов угловые башенки, `vase` и обелиски на `parapet`; скатная кровля за парапетом.
- **Стена:** три части: `rust` или тёмный камень на 1–2 этажа, тело с `pilaster` большого ордера, верх с мощным `cornice`; `belt`; арки проездов на 2–3 этажа; `bay`.
- **Окна:** `win.ratio` 1,6:1; обрамлены на нижних и верхних этажах, середина проще; `win.head` полуциркульная на верхнем этаже.
- **Декор:** `relief` (звёзды, снопы, гербы, венки), `balustrade` на балконах, `storefront` в цоколе.
- **Палитра:** бежевая керамическая плитка, охра, розовато-песочная штукатурка, тёмно-красный гранит цоколя.
- **Ключ:** рустованный низ + большой ордер + тяжёлый карниз; для высоток уступы и шпиль.

## 4. Стили 1950 – настоящее время

### `brutalist` — брутализм (1950–1970-е)
- **Силуэт:** массивные объёмы, нависающие консоли, отдельно стоящие башни лестниц и лифтов; `roof.flat`.
- **Стена:** бетон со следами опалубки, большие глухие плоскости, `fin`, повторяющийся модуль ячеек.
- **Окна:** глубоко утоплены; щелевые или `band`; тёмное стекло.
- **Декор:** нет; пластика самих объёмов.
- **Палитра:** серый бетон в нескольких тонах, потёки.
- **Ключ:** серый бетон + консоли + глубокие проёмы.

### `postmodern` — постмодернизм (с 1980-х)
- **Силуэт:** цитаты классики в увеличенном виде: разорванный `pediment`, `tower`-ротонды, `spire`; асимметрия.
- **Стена:** камень в сочетании с зеркальным стеклом; `stripe`; упрощённые цилиндрические колонны; огромный `keystone`; `arcade`.
- **Окна:** квадратные сеткой; `win.special` круглое и полукруглое.
- **Декор:** сам набор цитат; цвет как декор.
- **Палитра:** розовый, терракота, бирюзовый, кремовый, зеркальное стекло.
- **Ключ:** гипертрофированный фронтон или арка + квадратные окна + яркий цвет.

### `contemporary` — современная архитектура (XXI век; периодизация, а не стиль)
- **Силуэт:** простые или наклонные объёмы, консоли, стилобат с башнями; `roof.flat`, зелёные кровли.
- **Стена:** `curtain`; навесные панели разных оттенков; ламели.
- **Окна:** панорамные (уже есть); нерегулярный шаг («штрихкод»); `win.ratio` 2,5:1 от пола до потолка.
- **Декор:** нет; `storefront` в стилобате.
- **Палитра:** белый, серый, антрацит, дерево, одиночные акцентные цвета.
- **Ключ:** стекло + случайный ритм узких высоких окон.

## 5. Что добавлять в первую очередь

Примитивы упорядочены по числу стилей, которые они открывают.

1. **`cornice`, `belt`, `rust`, `plinth`-материал** — горизонтальное членение. Нужно почти всем стилям до 1955 года.
2. **`win.head`, `win.frame`, `win.ratio`, `win.glazing`** — параметры оконного шейдера. Одна форма перемычки уже различает классику, романику, готику и мавританский стиль.
3. **`pilaster` / `fin`** — вертикальное членение: классицизм, неоренессанс, ар-деко, сталинский ампир, постконструктивизм, брутализм.
4. **`band` / `curtain`** — функционализм, конструктивизм, интернациональный стиль, современная архитектура.
5. **`portico` + `pediment`, `attic`** — классицизм, ампир, сталинский ампир, постмодернизм.
6. **`bay`, `risalit`, `gable`, угловая `tower`** — эклектика, викторианский стиль, модерн, северный модерн.
7. **`stripe`, `lombard`, `merlon`, `kokoshnik`, `pinnacle`** — узнаваемые признаки отдельных неостилей.
8. **`setback`, `spire`** — ар-деко и сталинские высотки.

Палитры стилей ложатся в существующий механизм `WALL_PALETTES`: к выбору по типу здания добавляется выбор по стилю.
